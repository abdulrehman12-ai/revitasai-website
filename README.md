# Revitas AI public website

This is a static public marketing site for `revitasai.com`.

## Safety boundary

The site must remain separate from the Revitas staging application. It deliberately does not provide authentication, collect form data, advertise HIPAA compliance, or accept PHI/CPT content.

## Deploy on Vercel

Import this repository into Vercel as a static site. No build command is required. Connect only `revitasai.com` and `www.revitasai.com` to this project; do not connect those domains to the staging application.
